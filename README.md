# 🐍 Учебные проекты по Python

Данный репозиторий содержит материалы и проекты, выполненные в рамках курса по изучению языка программирования **Python**. Основная цель — закрепить теоретические знания на практике и создать работающие приложения.

---

## 📂 Содержание

Репозиторий структурирован по урокам и включает:

- **Последовательные уроки (Lesson 1–8)**  
  Папки с материалами и заданиями к каждому занятию курса. Они отражают постепенное изучение основ Python: от самых первых шагов до более сложных тем.

- **Финальный проект (Папка `Bot`)**  
  В качестве итоговой работы был разработан простой бот для социальной сети ВКонтакте (VK). Этот проект демонстрирует применение полученных знаний для создания приложения с реальным интерфейсом взаимодействия (API).

---

## ⚠️ Важное примечание

- **Актуальность**: Финальный проект — это бот образца **2019 года**. В связи с возможными изменениями в API ВКонтакте, его работоспособность в текущем виде не гарантируется.  
- Репозиторий в первую очередь ценен как **архив учебного процесса** и пример кода того периода.
